# Creative Direction — Modern Clinical × AI Engineering Portfolio

Design a premium portfolio using the same visual language as the provided reference. Do **not** copy the layout directly. Instead, reinterpret its design principles into a unique, award-quality AI engineering portfolio.

## Overall Style

The website should feel like a fusion of:

* Apple
* OpenAI
* Linear
* Vercel
* Stripe
* Notion

with the calm, trustworthy visual identity of the provided Modern Clinical theme.

The emotional response should be:

> "This engineer builds secure, intelligent systems that can be trusted."

The interface should communicate precision, intelligence, elegance, confidence, and technical excellence.

# Overall Impression

The final design should feel like the website of an elite AI engineer working on products used by governments, Fortune 500 companies, healthcare organizations, or cutting-edge AI startups.

It should evoke trust before excitement.

It should look timeless rather than trendy.

The user should feel:

"This engineer builds intelligent systems that are reliable, secure, and beautifully engineered."

The final result should be portfolio-quality enough to impress senior engineering managers, CTOs, AI researchers, and recruiters within the first ten seconds of visiting the site.
